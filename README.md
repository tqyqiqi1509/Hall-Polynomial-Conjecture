The manuscript states integral Hall-polynomial existence for every representation-finite algebra over a finite field, on every conservative finite extension. It includes its AI-contribution disclosure.

## Build

Run `pdflatex main.tex` twice with all ten TeX files present. The supplied PDF has 34 pages. `SHA256.json` records all ten sources and the PDF. The complete release archive includes these eleven files and the manifest.
