# Hall Polynomial Conjecture

**Qiyue Tang**

Manuscript: *Hall polynomials for geometrically standard algebras*.

- [Read the paper](Hall-Polynomial-Conjecture.pdf)
- [LaTeX source](main.tex)

The manuscript concerns integral Hall polynomials for geometrically standard representation-finite algebras over finite fields and its odd-characteristic corollary.

## Build

Compile main.tex with XeLaTeX twice. Keep all .tex files in the same directory.
